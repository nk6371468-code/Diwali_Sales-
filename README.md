# Diwali Sales Analysis

This project focuses on analyzing **Diwali sales data** to understand customer purchasing behavior, sales trends, and product preferences. The dataset includes customer demographics, location, occupation, product categories, number of orders, and purchase amounts.

### Project Objectives

* Clean and preprocess the sales dataset.
* Handle missing and unnecessary data.
* Perform exploratory data analysis (EDA).
* Analyze sales based on gender, age group, state, occupation, and product category.
* Create visualizations to identify important trends and patterns.
* Generate meaningful business insights from the data.

### Tools & Technologies

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **Jupyter Notebook**

### Key Analysis

The project explores customer demographics, geographical sales patterns, popular product categories, occupation-wise purchasing behavior, and order trends.

### Learning Outcomes

This project helped me gain practical experience in **data cleaning, exploratory data analysis, visualization, and extracting insights from real-world sales data**.

### Future Scope

The analysis can be extended with **customer segmentation, sales prediction, interactive dashboards, and machine learning techniques**.
